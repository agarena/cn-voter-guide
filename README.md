# cn-voter-guide — 人大选举选民参与指南

> 让你的 AI 智能体变成一个有据可查的选举参与顾问：照法条和官方公告回答**怎么参加县乡两级人大代表选举、去哪查信息、意见怎么提**，每句关键事实带出处，判断留给你自己。

2026—2027 年全国县乡人大换届正在进行中（多数地方 2026 年 11—12 月投票），现在装上正赶上登记和投票期。

## 安装：把这句话发给你的 AI

**最省事的装法**——把下面这句话原样发给你正在用的 AI 智能体（ZCode、Claude Code 等任何支持技能目录的智能体都行）：

```
帮我安装 cn-voter-guide 这个 skill：把 https://github.com/aipanini/cn-voter-guide 克隆到我的智能体技能目录里（技能目录在哪看你的文档；找不到就先问我在用哪个智能体，再从 GitHub 仓库 README 找对应位置）。
```

它会替你完成克隆和放置。装完直接问它选举问题就行。

### 手动安装（两条路）

```bash
# 方式一：git 克隆（把 <技能目录> 换成你的智能体的技能目录）
git clone https://github.com/aipanini/cn-voter-guide "<技能目录>/cn-voter-guide"
```

常见智能体的技能目录位置：ZCode / 通用 `~/.agents/skills/`，Claude Code `~/.claude/skills/`，Codex `~/.codex/skills/`（以你所用智能体的文档为准）。

方式二：本页绿色 **Code → Download ZIP**，解压后把 `cn-voter-guide` 文件夹整体放进技能目录。

**零依赖**：普通使用不需要装 Python、不需要跑任何脚本——数据和资料都在包里；`scripts/` 目录只有维护者更新数据时才用。智能体有联网检索能力时体验最好（能现场核实最新日期），没有也能用内置数据，只是会看到"数据截至某日"的声明。

## 能干什么

| 你这样问 | 它这样答 |
|---|---|
| 「我在通州，这届还来得及投票吗」 | 先确认你所在区县 → 核对数据时效 → 登记/选举日/你符合基本条件、名单去哪核对 |
| 「我不是本地户口，能在居住地投吗」 | 人户分离三条路（回户籍地 / 书面委托 / 凭证明在居住地参选）及各地门槛 |
| 「我们县选举日是哪天？候选人名单哪看」 | 查内置数据带来源；未收录就现场联网检索官方公告；附"选举日 15 日前/7 日前看候选人榜"的时点 |
| 「选举日我出差了怎么办」 | 委托投票四要件：书面、同选区、经选举委员会同意、一人最多受托 3 人 |
| 「选民名单把我漏了 / 我有意见」 | 公布之日起 5 日内向选举委员会申诉 → 不服可选举日 5 日前起诉；漏登可要求补正 |
| 「我有个建议想反映上去」 | 按事项分流渠道（代表联络站 / 12345 / 信访），并帮写成"事实+依据+诉求"的书面材料 |
| 「网上什么都查不到」 | 打 12345：「我是 XX 县居民，请告诉我本县人大换届选举委员会的联系方式」 |

三条边界，先说清楚：它**不做资格终局判定**（判"你没有资格"这种事留给选举委员会和法院，它只做清单式自查和引导）；**不编造查不到的信息**（查不到就说查不到，然后教你怎么查）；时间数据**2027 年 3 月后过期**（届时不更新即失效，会明确告知）。

## 适合谁

- 装了 AI 编程智能体的开发者：换届期自己或替家人朋友问"能不能投、怎么投"；
- 想搞清楚选举参与的普通人：你不装它，但你可以问装了它的人；
- 不适合的期待：想拿它当"资格判决书"或"选举进度新闻源"——这两样它刻意不做。

## 维护者说明（数据怎么更新）

```bash
python scripts/fetch_election_dates.py   # 按白名单抓取种子站点，产出线索文件
python scripts/validate_data.py          # 校验 data/election_dates.json（格式/链接/过期）
```

采集纪律内置于脚本：限速 1 请求/秒、遵守 robots 协议、只抓公开公告列表页。产出的是"线索"（含日期的公告行），维护者核实后合入 `data/election_dates.json` 并提交——git 历史即换届档案。2027 年 3 月本轮结束后数据冻结；约 2031 年下轮换届，站点白名单与脚本直接复用。

## 口径与免责

本仓库内容为法律法规及官方公开信息的汇编（法条与官方公告按《著作权法》第五条不受著作权保护），每条关键事实在 references 文件中注明出处；法条以[国家法律法规数据库](https://flk.npc.gov.cn)为核校基准。所有日期、名单、程序以**当地选举委员会公告**为最终依据，本技能不构成法律意见。

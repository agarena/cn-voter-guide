# 检索指引：去哪看 + 怎么搜 + 顺藤摸瓜

回答"在哪查/有没有/是哪天"类问题的操作手册。总原则：**查到的事实必须带来源链接；查不到就明说未找到，然后走信息链或 12345；绝不编造。**

## 一、分层信源表（先去哪看）

| 层级 | 有什么 | 去处 |
|---|---|---|
| 全国 | 法律原文、总体口径、新闻发布会数字 | [国家法律法规数据库 flk.npc.gov.cn](https://flk.npc.gov.cn)、[中国人大网 npc.gov.cn](http://www.npc.gov.cn) |
| 省级 | 换届时间决定（总时钟）、省级专题页 | 省人大常委会官网（部分省有换届专题，如[江苏](https://www.jsrd.gov.cn/zt/d_xxrdhjxj)、[云南](https://www.ynrd.gov.cn/html/ztkj/yunnsxxrdhjxj)）；省级党媒客户端 |
| 县级 | 选举委员会公告（选举日、选民登记安排、当选名单）——**进度信息的真正源头** | 县人大子站（域名规律见下）、县政府门户"通知公告/公示公告"栏 |
| 乡镇/选区 | 选民榜、候选人公示 | 法定形态是**线下公告栏张榜**：社区居委会、村委会、单位公告栏；线上零散 |
| 找不到门 | 任何环节卡住 | **12345 兜底**（话术见下）、社区/街道办当面问 |

县人大网站域名三种常见形态：`rd.县拼音.gov.cn`（子域）、`县拼音rd.gov.cn`、独立缩写域名（如 tqx.gov.cn）。找不到就从县政府门户的"政府机构/人大"入口进。

## 二、搜索模板（代入用户所在地）

```
{县名} 选举委员会 公告
{县名} 第X届 人大代表 选举日
{县名} 人大换届 选民登记
{县名} 选举日 site:gov.cn
{县名} 正式候选人 名单 公示
```

技巧：

- **优先 site:gov.cn 限定**官方域；`rd.` 前缀与拼音缩写域名都存在，别只认一种。
- **县官网没有 ≠ 没发布**：不少县公告只发微信公众号或省级媒体（调研实例：云南维西、四川天全）——改查微信公众号（微信内搜"县名+选举"或搜狗微信搜索）与省级党媒转载（川观、新华日报等）。
- **转载稿规则**：商业门户/媒体转载可用，但须标注"转载自 XX 官网"，尽量回溯官方原文链接再引用。
- **法条版本**：搜到的条文先验版本——2015 版与 2020 版选举法条号差 1，以 flk.npc.gov.cn 为准。
- **时间过滤**：检索结果按时间排序，选 2026 年内的。

## 三、信息链（顺藤摸瓜）

每一步查到的东西是下一步的搜索词：

> 省人大换届决定（拿本县换届窗口）
> → 搜「{县名} 选举委员会 公告」（拿选举日、选区划分、登记期）
> → 按倒推表定时点（−20 日选民榜、−15/−7 日候选人榜）
> → 到选区公告栏/社区居委会看榜（选民名单、候选人公示法定线下张榜）
> → 找不到或存疑 → 12345 要选举委员会联系方式 → 电话核实

## 四、12345 兜底话术

> 「我是 XX 省 XX 县/区的居民，正在进行的县乡人大换届选举，请告诉我本县（区）选举委员会或选区工作组的联系方式。」

要点：**报准所在区县**；12345 的本职是政务咨询与转办（国办发〔2020〕53 号），它不一定直接答选举问题，但能告诉你门在哪。注意分工：一般咨询、找门 → 12345；名单申诉（5 日窗口）→ 直接找选举委员会；换届违纪 → 12380；涉嫌违法犯罪 → 公安机关。

## 五、候选人与当选信息的专项提示

- 候选人名单：先线下（选区公告栏、−15/−7 日两个时点），线上查县人大官网公告栏与公众号。
- 了解候选人最有效的合法机制：**要求选举委员会组织候选人与选民见面会**（第三十四条，选民提出即可触发）——见面会信息问选区工作组。
- 当选名单与代表资格公告：选举日后 1—2 个月内由县人大常委会发布，查县人大官网"选举任免/公告"类栏目（实例：[隆回县第十八届人大代表资格公告，399 名按乡镇分组](http://rd.longhui.gov.cn/lhxrdw/xjrm/202609/5a23e141fbeb40d0b9f6973dc16f9179.shtml)）。

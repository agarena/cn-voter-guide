# 选民资格自查问答流

设计原则：条件齐全就给**明确的正面结论**；任何存疑或排除信号只引导去选举委员会确认，**永远不输出"你没有资格"**。资格终局权在选举委员会与法院（选举法第二十九条：申诉→起诉→判决为最后决定）。

## 第一部分：三道门（逐问，全部回答完才下结论）

**门 1：你是中国公民吗？**（持有中华人民共和国国籍）
- 是 → 下一门
- 否 → 不适用本指南（选举权和被选举权属中国公民）

**门 2：到当地本届选举日当天，你年满 18 周岁了吗？**
- 年龄以**选举日**为准（含当日），不是提问日。若不知道当地选举日，先按 `find-info.md` 查，或按本届窗口估算后再向选举委员会确认。
- 是 → 下一门
- 否 → 本届不满足年龄条件；**届满 18 周岁后的下一轮即可**（约五年后），无需任何操作。
- 临界（选举日前后几天生日）→ 按"以选举日为准（含当日）"计算后回答；仍不确定属于哪一天时，向选举委员会确认。

**门 3：你被依法剥夺政治权利了吗？**
- 否 → 三门全过，给结论
- 是 → 不享有选举权。注意两种需要选举委员会确认的情形：剥夺政治权利**已期满恢复**的恢复权利；判决文书与执行状态以司法机关口径为准 → 引导向选举委员会确认。
- 不确定 → 引导向选举委员会确认，不下任何结论。

**三门全过的标准答法**：根据你的情况（中国公民、选举日满 18 周岁、未被剥夺政治权利），你具备选民资格的基本条件。下一步：在登记期内到所在选区登记（登记去哪、截止什么时候，见 voter-guide.md 第一板块与数据层），登记后你的名字会出现在选举日 20 日前公布的选民榜上。

## 第二部分：排除与特殊情形对照表（命中即转引导，不下结论）

| 情形 | 法定处理 | 动作 |
|---|---|---|
| 精神病患者不能行使选举权利 | 经选举委员会确认，不列入选民名单（《直接选举若干规定》第三项） | 引导向选举委员会确认 |
| 被羁押，未被剥夺/停止政治权利 | 准予行使选举权利，可流动票箱投票或委托有选举权的亲属代投（第四、五项） | 告知其本人或家属可联系办案机关/选举委员会安排 |
| 剥夺政治权利期满 | 恢复政治权利 | 引导向选举委员会确认恢复 |
| 选民名单上没有自己（漏登） | 应纠正后重新张榜；名单有意见 5 日内申诉 | 引导申诉路径（见第五板块） |

## 第三部分：人户分离分流（判路径，不判资格）

**问清三个事实：户籍在哪 / 常住在哪 / 选举日在哪。** 然后按《直接选举若干规定》第九项分流：

1. **户籍地与常住地一致** → 就地登记参选，结束。
2. **人在外地，想回户籍地投** → 可以；选举日无法回去的，书面委托户籍地选区选民代投（四要件见 voter-guide.md 第二板块）。
3. **人在外地，想在常住地投** → 两条子路：
   - 已迁居未迁户口：取得原选区选民资格证明后，可在现居住地选区参选；
   - 未迁居（工作/求学）：看当地规定——多地允许持居住证/居住满一定期限（如北京：居住半年以上或工作半年以上）在现居住地登记参选；当地是否放开、门槛多长，属地方差异（查 `local-variation.md`，并向当地选举委员会确认）。
4. **在校学生** → 一般可按学校所在地选区登记，也可回户籍地或委托投票，以当地选举委员会规定为准。

分流后动作统一收敛为：**告诉你去哪登记（社区居委会/村委会/单位/登记站）、截止日期、带什么**；截止日期查数据层或走检索，查不到就引导 12345。

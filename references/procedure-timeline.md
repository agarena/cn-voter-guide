# 法定时点倒推表（以选举日为锚）

县乡两级人大代表直接选举的全部关键时点都由选举日倒推确定。拿到当地选举日后，按下表推算并逐项提醒用户：

| 时点 | 事项 | 依据 |
|---|---|---|
| 选举日 −60 日左右 | 省人大常委会换届决定陆续公布，县级选举委员会设立、选区划分 | 《选举法》第十、十一条 |
| 选举日 −60 至 −30 日 | 选民集中登记期（各地不一，以当地公告为准） | 各地选举委员会公告 |
| **选举日 −20 日** | **选民名单张榜公布** | 第二十八条 |
| 名单公布起 **5 日内** | 对名单有意见向选举委员会申诉；选举委员会 3 日内处理 | 第二十九条 |
| **选举日 −15 日** | 初步代表候选人名单及基本情况公布 | 第三十二条 |
| **选举日 5 日以前** | 对申诉处理决定不服的，可向人民法院起诉（法院须在选举日前判决） | 第二十九条 |
| **选举日 −7 日** | 正式代表候选人名单及基本情况公布 | 第三十二条 |
| 选举日前 | 选民可要求选举委员会组织候选人与选民见面 | 第三十四条 |
| **选举日** | 投票（投票站/选举大会/流动票箱）；**当天停止候选人介绍** | 第三十四、三十八条 |
| 选举日后 | 当选名单公告、代表资格确认，两个月内召开新一届人大一次会议 | 《地方组织法》 |

## 使用规则

1. 用户只给省份、没给县时：先用省窗口给粗范围（"本届应在 X 月到 Y 月之间"），再走 `find-info.md` 查县选举日。
2. **任何倒推日期都要标注"以当地选举委员会公告为准"**——选举日可以被调整（实例：湖南隆回由 8-19 调整为 8-21；四川天全由 10-19 推迟至 10-30）。
3. 用户问"现在该干什么"：拿今天日期对照本表，告诉用户当前阶段与下一个截止日，结论收敛为三类之一（去登记 / 已截止+补救 / 本轮已结束）。
4. 选举日之后的追问（结果、代表名单）：当选公告由县人大常委会发布，走 `find-info.md` 检索县人大官网。
